# Magenta Lightsaber

A Forge mod for **Minecraft 1.21.1** that adds a hand-modeled gold-and-silver lightsaber with a blazing magenta plasma blade.

## Features

- Detailed 3D hilt with gold, silver, dark grip and a magenta kyber crystal ring.
- Custom 3D magenta blade with a white-hot core, an inner plasma glow and a soft outer aura.
- **Right-click** to ignite or retract the blade. The item model, tooltip, sounds and particles change with the state.
- Active blade hits harder and has sword-like attack speed; the hilt is weak when retracted.
- Fire resistant, unbreakable, epic rarity, own creative tab and a crafting recipe.
- English and Spanish translations.

## Crafting

```
 G
ISI
 M
```

- `G` = Gold Ingot
- `I` = Iron Ingot
- `S` = Netherite Ingot
- `M` = Magenta Dye

## Installation

1. Install **Minecraft Forge 1.21.1** (52.x) with Java 21.
2. Drop `magenta_lightsaber-1.0.0.jar` into `.minecraft/mods`.
3. Launch the game. The saber is in the **Magenta Lightsaber** creative tab or can be crafted.

## Controls

| Action | Result |
| --- | --- |
| Right-click (air or most blocks) | Ignite / retract the blade |

## Build

```bash
./gradlew build
```

The jar is written to `build/libs/`.
